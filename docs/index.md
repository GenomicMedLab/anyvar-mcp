# AnyVar MCP Server

**Variation data for AI agents.** This prototype connects an
[AnyVar](https://github.com/GenomicMedLab/anyvar) service to MCP-compatible
hosts. Its tools let agents register supported variant nomenclature,
retrieve [GA4GH VRS](https://vrs.ga4gh.org/en/stable/) objects, search regions,
and follow available mappings.

## Who is this for?

- **Agent developers** building research or variant-curation workflows in an
  MCP-compatible host.
- **Researchers and curators** who need answers tied to VRS identifiers and
  AnyVar responses.
- **Teams running AnyVar** that want to offer agent access through defined tools.
